# Game Practice Research

研究“某项游戏技术解决什么问题、在实际项目中如何实现、代价和适用边界是什么”，交付可独立阅读的 Markdown 文章，而非搜索链接清单。默认中文正文，保留关键英文或日文术语以及原始资料标题；用户指定的语言、范围和格式优先。

## 确定研究问题

- 从请求中提取技术问题、目标平台、引擎、时间范围和研究深度。缺少技术主题时先询问；已有主题时，只有会显著改变结论的歧义才需要澄清，其他事项说明假设后继续。
- 将宽泛主题收束成几个能由资料回答的问题，例如表示方式、数据流、更新策略、性能瓶颈、生产管线和失效场景。用户仅要求概览时相应缩短，不擅自扩展成全领域综述。
- 简要告知检索范围及完成标准：核心机制有证据、案例与适用条件明确、重要缺口已披露、文章已保存且引用可追溯。

## 检索与取证

开始检索时阅读 [来源目录](references/sources.md)，根据主题选择检索路线。GDC Vault 和 CEDEC 是默认检索入口；再覆盖与问题相关的大会、工作室或厂商资料，不机械遍历整个目录。用户限制来源时遵循其要求。

1. 建立中、英、日关键词及别名，包括技术名、游戏名、引擎名、作者和相邻术语。先找候选演讲，再以准确标题、作者和年份查找讲稿、录像、论文、代码及后续版本。
2. 使用当前环境实际可用的搜索、浏览、连接器或公开网页读取工具。搜索摘要和聚合页仅作线索，重要结论要打开原始材料核验。没有可用的在线访问能力时，使用用户材料并清楚说明范围，不能声称完成了在线检索。
3. 优先阅读作者或机构发布的讲稿、带备注幻灯片、录像、论文和官方实现。论文说明方法，项目演讲支持生产实践；二者不能互相替代。新闻稿、二手解读和周报用于发现资料，独有信息须标明来源性质。
4. 在工作区临时笔记中建立证据记录：来源编号、原始标题、作者/机构、年份、公开链接、已读取的材料类型、页码/章节/时间戳、支持的结论及限制。对于视频，只按实际观看或取得的字幕内容引用；自动转录中的术语、数字和单位需重点复核。
5. 遇到登录、付费或链接失效，先查作者主页、公司公开发布和同场演讲的公开版本。记录“仅元数据/摘要可读”等访问状态，不根据标题补写实现，不绕过访问限制。只有受限内容对结论不可或缺时才请求用户提供合法可用的材料或访问方式，其余研究继续推进。
6. 围绕关键主张交叉核对独立来源。相同演讲的 PDF、录像、转载和摘要算同一证据链；一个资料不足以支持“业界普遍采用”。找到相互矛盾的结论时，检查版本、平台和工作负载差异，仍无法解释则保留分歧。

当核心问题都有足够材料支持，且新增检索主要重复已知信息时结束。来源少时如实缩小结论范围，不用固定篇数凑数量。日期以材料的发表时间为准，不能把网页更新时间当成技术首次出现时间。

## 分析实现与取舍

对主要技术路线，按问题需要解释输入输出、数据表示、算法步骤、运行或构建时的数据流、与引擎的集成点、成本和失效条件。区分 CPU/GPU、离线/运行时、算法本身/制作管线，避免只罗列术语。

- 明确区分：**来源明确陈述**、**对多份资料的归纳**、**本文推断或建议**。论文演示、公开原型、厂商示例和商业游戏采用分别表述；声称某游戏采用某方案必须有对应证据。
- 性能数据尽量保留硬件、分辨率、场景、质量设置、版本和测量范围；未知条件标为未报告。跨平台或不同测量口径不能直接得出速度排名，“最多提升”不能改写成普遍提升。
- 方案比较围绕共同决策条件展开，如画质、时间与内存预算、动态场景、内容约束、平台适配和维护成本。区分历史方案及其当时约束与当前公开进展，不把发布时间晚自动等同于更优。
- 伪代码、公式和图示仅在能澄清机制时添加。自行整理的伪代码标为说明性重构，不能冒充项目源码；关键参数和公式仍需来源支持。

## 撰写并交付

写作前阅读 [文章与引用规范](references/article-guide.md)。先给出回答研究问题的主要发现，再沿机制与案例展开，最后给出有条件的选型建议、尚未解决的问题和来源。以解释和综合为主，不逐篇摘要拼接。

保存路径优先采用用户指定位置，其次遵守当前工作区的 AGENTS.md 和输出目录约定；没有约定时写入 `outputs/<topic-slug>-research.md`。检索笔记和下载材料放在 `work/` 等临时目录，不混入最终文章。不覆盖无关的已有文件。

交付前检查：

- 技术核心结论、项目采用情况及定量数据有就近引用；定位信息对应实际读过的内容。
- 每个引用编号都能找到完整来源；访问受限、证据不足及推断没有被写成已验证事实。
- 文章回答原问题，说明机制与取舍，比较项的条件一致或已明确注明差异。
- Markdown 文件实际存在，引用和相对资源路径正确；若核验时来源不可访问，保留已知公开入口并披露状态，不宣称链接全部验证通过。

最终回复给出文章链接、少量核心发现和影响结论的重要限制。没有完成在线研究时，明确将产物标为基于现有材料的初步稿。
