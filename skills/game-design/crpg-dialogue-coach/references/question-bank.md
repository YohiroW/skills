# 按当前开放点选择问题

每轮挑一个已具备前提、最影响后续写作的问题。跳过用户已经确定的内容。选项与推荐方向根据其回答重新生成，下面的问法不预设作品答案。

| 当前开放点 | 前提或触发情境 | 可用问法 | 回答影响什么 |
| --- | --- | --- | --- |
| 场景用途 | 用户有模糊点子，尚未说明想写什么 | 这次交谈结束时，你最希望玩家想做哪件事？ | 剧情功能、出口和需要披露的信息 |
| 玩家体验 | 用户只说要“有趣”或“吸引人” | 玩家和这个人说话时，最想让他好奇、戒备还是亲近？也可以用自己的词描述。 | 张力、信息缺口与人物距离 |
| 入口局面 | 场景用途已知，开头仍像泛泛聊天 | 玩家走近之前，对方正在做什么事？ | 可以打断、观察或参与的行动 |
| NPC 当前目标 | 人物只有身份或性格标签 | 他这一次最希望从玩家这里得到什么？ | 说话意图、筹码与拒绝理由 |
| 人物矛盾 | 欲望已知，但人物过于平直 | 哪件事会让他违背自己的原则，或让他的判断失准？ | 脆弱、盲点与转折 |
| 玩家知情范围 | 已有秘密或反转 | 玩家此刻已经知道什么，靠什么线索怀疑他？ | 公平提示、提问方式与披露时机 |
| 玩家身份与历史 | 用户希望场景更有扮演感 | 哪一项玩家身份或过去行为，最会改变他这次的判断？ | 称呼、态度、可用论据或后续回应 |
| 不同参与方式 | 目前选项只是在换一种问法 | 除了追问，玩家还可以用哪种手段推进或结束这次交涉？ | 选项之间的意图区别 |
| 选择的取舍 | 已有重要决定，但各答案代价模糊 | 玩家保护一项利益时，会让谁或什么承担代价？ | 风险、关系与结果 |
| 同伴介入 | 用户已确定有相关同伴 | 这个同伴为什么要在此刻插话，玩家能怎样对待这次介入？ | 同伴自主性、关系与目标冲突 |
| 再次见面 | 本次选择已知，用户需要后续呼应 | 下次见面时，对方记住哪一件事，会最明显地改变开场？ | 可保存的具体事实与反馈时机 |
| 分支规模 | 场景选择已知，预算仍开放 | 哪些选择值得持续分开，哪些在得到回应后可以回到同一场景？ | 写作量、回汇与长期兑现 |
| 失败进路 | 用户要求检定、拒绝或任务失败 | 失败后，你希望玩家付出什么代价，又能继续做什么？ | 失败内容、其他办法与局面变化 |

## 推荐项怎么给

推荐依据用户已选择的体验和限制，例如：“你希望玩家保持怀疑，我推荐对方先答应帮忙、却回避说明代价，这会留下可以追问的具体缺口。”

每个方向只改变当前一项核心决定。可以比较坦白承认、自我辩护、转移话题等回应手段；是否合适取决于人物此刻的目标与已确定的性格。

用户表示不知道时，给两三个低成本情境帮助选择。用户授权你决定时，采用一个方向并明示假设。未经接受的推荐不进入“已确定”记录。

## 把矛盾问成一个取舍

先指出当前两个决定的具体冲突，再问用户更重视哪一项。例如，用户希望 NPC 已经知道失窃者身份，又安排他真心要求玩家辨认失窃者；可以问他此刻是在求证、试探玩家是否诚实，还是准备调整知情设定。

不用为了问得深入而添加当前作品不需要的世界历史、人物心理诊断或每个选项的所有远期结局。问题是否值得提出，取决于答案会不会改变本次稿件。
